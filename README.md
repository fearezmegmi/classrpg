Ez a repo azoknak van, akik szeretnék elindítani a régi ClassRPG szervert, hogy barátokkal játszanak rajta vagy csak szeretnék megnézni a mód forráskódját.
Ez a legutolsó 2018-2019 körüli forráskód ami nálam volt, OpenMP kompatibilisre alakítva.

A repo tartalmazza a szerver fájlokat is, adatbázist neked kell létrehozni és a forráskódot lefordítani.
